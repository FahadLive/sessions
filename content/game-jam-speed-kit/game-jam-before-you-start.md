# Before I start a jam

Run through this **the night before**. It takes 20 minutes and buys you the first two hours.

## My template project

- [ ] I have a `jam-template` folder (a copy of my finished starter, game-specific bits removed)
- [ ] It opens in my version of Godot with no errors, and **F5** runs it
- [ ] It already has: `GameState` autoload, a player that moves, restart on **Space**, a HUD with a score
- [ ] The renderer is **Compatibility**
- [ ] Pixel art filter is set to **Nearest** (if I'm doing pixel art)
- [ ] The Web export preset is already added, and **Thread Support is off**

## Folders and credits

- [ ] The folders `art`, `audio`, `scenes`, `scripts`, `ui` exist
- [ ] `CREDITS.txt` exists with the four-field format: **asset, author, link, license**
- [ ] I will paste in each credit **the moment** I add an asset

## Tools

- [ ] Godot (matching version) and its **export templates**
- [ ] My itch.io account works (I've logged in this week)
- [ ] Bookmarks: [Kenney](https://kenney.nl/assets), [OpenGameArt](https://opengameart.org), [Freesound](https://freesound.org), [jsfxr](https://sfxr.me)
- [ ] At most **one new tool** I want to learn this jam (and I know which)

## The jam itself

- [ ] I've read the jam's rules: team size, asset rules, **rules on AI-generated assets**
- [ ] I have an **AI tutor opening prompt** ready ([AI tutor rules](/game-jam-ai-tutor-rules/))
- [ ] I'll write the **core loop in one sentence** before I open Godot
- [ ] I'll write a **cut list** on day one: what I will NOT build

## Habits

- [ ] **Backup:** every hour I zip my project folder (`mygame-1400.zip`)
- [ ] **Test export:** I'll do one around the halfway point, not the last night
- [ ] **Sleep.** A rested brain debugs in minutes what a tired one can't in hours
